# Дипломная инфраструктура

Развёрнута в Yandex Cloud с помощью Terraform, настроена через Ansible.

## Что внутри

- **2 веб-сервера** (web-01, web-02) с nginx — в разных зонах доступности для отказоустойчивости
- **ALB (балансировщик)** — распределяет трафик между веб-серверами, проверяет их healthcheck'ом
- **Бастион** — единственная точка входа по SSH, публичный IP закреплён статически
- **NAT-шлюз** — даёт приватным машинам доступ в интернет без публичных IP
- **Elasticsearch + Kibana** — сбор и просмотр логов nginx
- **Zabbix** — мониторинг серверов и дашборд
- **Снапшоты** — все диски бэкапятся раз в сутки, хранятся 7 дней

## Схема

ALB (порт 80) → web-01, web-02 (nginx)
SSH-доступ: только через бастион (ProxyJump/ProxyCommand)
Логи: nginx → Elasticsearch, смотрим в Kibana
Мониторинг: Zabbix Server + агенты на всех ВМ

## Как запустить

1. Скопировать `terraform.tfvars.example` в `terraform.tfvars` и заполнить
   свои значения (folder_id, ключ сервис-аккаунта, свой IP и т.д.)
2. `cd environments/prod && terraform apply`
3. Вписать IP бастиона в `ansible/inventory.ini`
4. `cd ../../ansible && ansible-playbook site.yml`
5. Сайт открывается по IP балансировщика, Kibana и Zabbix — по IP своих ВМ

## Безопасность

- Публичных IP у приватных машин нет — вход только через бастион
- Security groups ограничивают порты (SSH только с IP администратора)
- Секреты (tfvars, ключи) в git не попадают — есть только шаблон .example
- SSH доступ только по ключу, парольный вход отключён
